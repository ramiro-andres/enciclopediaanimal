# Internacionalización

La interfaz del atlas está en **español**.

## Uso actual

- Archivo: `js/i18n.js` (mapa plano clave → texto ES).
- HTML: `data-i18n`, `data-i18n-html`, `data-i18n-placeholder`, `data-i18n-aria`.
- JS: `I18n.t(key)` / `App.t(key)`.
- Sin conmutador ES/EN en la UI.

El contenido clínico (razas, fichas, glosario) también está en español en los datos.

## Por qué no hay API de traducción en runtime

La app es **PWA offline-first**. Un API externo (DeepL, Google, etc.) añadiría red, latencia, coste y no reduce LOC de análisis.

## Si se vuelve a añadir inglés (recomendado)

1. Archivos locales `data/i18n/es.json` y `data/i18n/en.json`.
2. Cargar solo el idioma activo; precachear ambos en el service worker.
3. Opcional: traducir claves nuevas en **CI/build** con un API, nunca en el navegador.
4. No autotraducir fichas clínicas sin revisión veterinaria.
